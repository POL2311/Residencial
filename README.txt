Proyecto base: Login Sistema Residencial (PHP + MySQL + Tailwind)

1. Crea la base de datos y tabla users (ver instrucciones que te dio ChatGPT).
2. Crea un archivo `.env` en la raíz del proyecto basado en `.env.example` y configura tus credenciales de base de datos.
3. Sube todos estos archivos a tu servidor PHP (por ejemplo, htdocs/residencial).
4. Accede a login.php desde el navegador.
